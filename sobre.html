Equipe e projeto

O CREDIT42 é um projeto desenvolvido para instituições financeiras que desejam ampliar seu alcance e explorar oportunidades de crédito para públicos que tradicionalmente enfrentam dificuldades para obtê-lo. Quando surgirem novas perguntas, o C42 está aqui para te dar a resposta! A equipe Meridiano Tech desenvolveu um sistema de score que permite realizar análises comparativas a partir dos indicadores apresentados na plataforma, contribuindo para a identificação de oportunidades em diferentes regiões.
