# Meridiano Tech - Inteligência Analítica para Oportunidades de Mercado

# 📒 Descrição
Sistema de análise de mercado voltado à integração, tratamento e visualização de dados econômicos públicos (incluindo APIs do Banco Central). A solução consolida informações complexas em dashboards interativos, fornecendo clareza estratégica para suporte à tomada de decisão e expansão de negócios.

# 🎯 Objetivo
- Coleta automatizada: Captura contínua e automatizada de dados econômicos de fontes públicas.
- Tratamento e padronização: Normalização e estrutura uniforme dos indicadores de mercado.
- Índice de Oportunidade (Score): Algoritmo próprio para cálculo de score de apoio à tomada de decisão.
- Dashboards interativos: Interface gráfica para análise visual e exploração intuitiva dos dados.
- Disponibilização via API: Endpoints estruturados para fácil integração e consumo por outras aplicações.

## Definition of Ready (DoR)

Uma funcionalidade é considerada **Ready** quando atende a todos os critérios abaixo:

- [ ] A necessidade do usuário está claramente descrita.
- [ ] O objetivo da funcionalidade está definido.
- [ ] Os critérios de aceitação estão documentados.
- [ ] As regras de negócio estão definidas.
- [ ] As fontes e dados necessários estão identificados.
- [ ] As dependências e impedimentos foram identificados.
- [ ] A história possui prioridade, sprint e estimativa.
- [ ] A equipe consegue desenvolver e testar a funcionalidade sem depender de informações ainda desconhecidas.

## Definition of Done (DoD)

Uma funcionalidade é considerada **Done** quando atende a todos os critérios abaixo:

- [ ] A funcionalidade foi implementada de acordo com os requisitos definidos.
- [ ] Todos os critérios de aceitação da User Story foram atendidos.
- [ ] O código foi testado e está funcionando conforme o esperado.
- [ ] Foram corrigidos os erros encontrados durante os testes.
- [ ] O código foi revisado por pelo menos um integrante da equipe.
- [ ] A implementação está integrada ao projeto sem conflitos.
- [ ] Os dados utilizados foram tratados e validados quando necessário.
- [ ] A documentação relacionada à funcionalidade foi atualizada.
- [ ] Não existem pendências conhecidas que impeçam a entrega da funcionalidade.
